#KindTickerHorizonRecordedHashOK
Chain recomputedEvery entry's hash equals SHA-256 of its canonical record with the previous hash inside it. A change anywhere breaks every later hash.
Head matchesThe last recomputed hash equals the head the pack claims, and the count equals the pack's count.
Server headsEach day's entry names a head and a count. The pack's entry at that count must carry that hash. If it does, nothing up to that count changed since that day, on the server's clock.
What this does not proveThat the prices in the marks were true on the day. A chain built from invented prices verifies. The cron marks and the named price feed are what answer that.

Source line: the same arithmetic ships inside the terminal; this page carries a copy of it, and the test suite checks the two are identical.
